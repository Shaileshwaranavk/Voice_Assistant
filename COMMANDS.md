# What Veera understands

Say **"Hey Veera"** first (or click him). Everything below is understood **on your PC** - no cloud model decides
anything. Gemini is used for exactly one thing: writing a **summary** when you say "summarize ...".

You can chain commands: *"open Chrome and go to Gmail then search for invoices"*.
"It / that / this" mean the file, folder or page you just worked with.

## Apps & windows
- open / launch **Word, Excel, Spotify, WhatsApp, Notepad ...** (already open? he brings it to the front)
- open **Chrome / Edge / Brave / Firefox** - "... with my work profile"
- switch to **Word** · bring Chrome to the front · close **Spotify** (asks first) · close this window
- minimize everything · show the desktop · restore windows · minimize / maximize **this window** / Chrome
- snap this window left / right · full screen · what apps are open · what am I looking at
- open the Start menu · show notifications · lock the computer · restart the computer · cancel the shutdown

## Browser
- go to **github dot com** · open YouTube dot com in Brave · open **my work Gmail**
- search the web for **...** · google **...** · search YouTube for **...** · search for ... on Bing
- new tab · close this tab · reopen the closed tab · next / previous tab · go to the **Gmail** tab
- go back · forward · refresh · zoom in / out · bookmarks · history
- what tab am I on · copy the link · download this
- read the page · summarize this page

## Files & folders
- create a folder called **Projects** on the desktop / in documents
- create a **Word / Excel / PowerPoint / text** file called **minutes** (in that / on the desktop)
- find my resume · find the invoice PDF in downloads · open the latest PDF · open it · open it in Word
- copy / move **X** to **documents** · rename it to **final report** · duplicate it
- delete **X** (asks first - goes to the Recycle Bin) · zip it · unzip it · show it in Explorer
- what are my recent downloads

## Documents (read locally, scans and images read with Windows OCR)
- read the invoice · read this PDF · read the text in note.png · read more
- what is the **deadline / total / customer / invoice number** in it · find the **email addresses** in it
- what do I need to do in this document (action items) · compare **A** and **B**
- **summarize** it / the page / the clipboard / the chat / my unread emails - *"in detail"*, *"action items"*, *"executive"*

## Email, chat, calendar (reads what is on screen in your signed-in apps)
- check my unread emails · find the email from **Rahul** about the **invoice** · emails with attachments
- read my latest email · open WhatsApp · what did **Rahul** send me on WhatsApp
- what is my next meeting · open my calendar · **check everything important** (briefing)

## Keyboard, mouse, clipboard
- type **hello world** · type **thanks** and press enter (asks first) · press **control s**
- copy · paste · cut · select all · undo · save · click the **Insert** tab · scroll down
- read the clipboard

## Media
- pause · resume · next song · previous · stop the music · skip forward 30 seconds
- play my **workout** playlist on Spotify · play **<song>** (YouTube)

## System
- volume, brightness, Wi-Fi, Bluetooth (turn on/off, connect, set to N, "make it ten")
- set this image as my wallpaper · open display / bluetooth / sound **settings** · battery / memory
- empty the recycle bin (asks first)

Anything risky - delete, close an app, restart, empty the bin, type-and-send, change Wi-Fi/Bluetooth - makes him ask
**"Shall I go ahead?"** and wait for a yes. Click Veera to stop a long task.
